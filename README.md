# PrepPlan

PrepPlan is an AI-powered interview preparation platform designed to help users practice interview questions, track their progress, and receive intelligent, automated feedback. Built with a robust React/Vite frontend and a secure Node.js/Express backend, it offers a seamless and responsive experience for job seekers.

---

## 🚀 Features

* **User Authentication:** Secure user registration and login.
* **AI Question Generation:** Dynamically generated interview questions tailored to user needs.
* **Session Tracking & Reports:** Detailed tracking of interview history with intelligent performance reports.
* **Secure Backend:** Token-based authentication using JWT.
* **File Handling:** Integrated middleware support for file uploads.
* **Responsive Dashboard:** A modern, clean frontend featuring an intuitive interview flow and user dashboard.

---

## 🛠️ Tech Stack

### Frontend
* **Framework:** React (via Vite)
* **Styling:** SCSS
* **Tooling:** ESLint, modern frontend build tools

### Backend & Database
* **Runtime & Framework:** Node.js, Express
* **Authentication:** JWT (JSON Web Tokens)
* **Database:** MongoDB (or preferred NoSQL/SQL database)
* **AI Integration:** Custom backend AI service integration

### How to get started
cd backend -> 
npm install -> 
nodemon server.js

cd frontend -> 
npm install -> 
npm run dev
